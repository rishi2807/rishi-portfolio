Workflow Hub: Meeting Management Redesign

Lead Content Designer · A/B Testing via Maze · Figma Variables · 2024

The problem

Cvent's Meeting Management platform split workflow components across separate, siloed pages. Admins setting up automations couldn't see how pieces connected, so changes broke other areas and support tickets piled up.

What I did

  • Introduced a centralised Workflow Hub consolidating all components.
  • Renamed confusing engineering shorthand to user language; added contextual tooltips.
  • Created a Workflow Map showing how settings affect each other.
  • A/B tested content and sequencing via Maze; shipped the better-performing variant.
  • Used Figma Variables for consistent states across light/dark and active/disabled.

Impact

  • 40% fewer support cases
  • 35% fewer navigation clicks
  • +12% SUS score
